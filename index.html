Keeping it up

Preview a session

Credit is the face value minus a discount for recent work of the same kind. The percentage is the average over the whole session, so it is lower than the first mile's value above. Strength sets are spread evenly over the exercises. The first three sets of an exercise count fully, and later sets of the same exercise count a little less each, so the number of exercises only matters once one of them goes past three sets.

History

Show more days

Credit is worked out per day for cardio and for each muscle group, then split across that day's runs, walks, or sets in proportion to each one's face value. So a fast run shows more than an easy one, and later sets of the same exercise show less.
